# docs/motion.md
16:9 · 1920×1080 · 30fps. 측정 기록이 아니라 기준 문서. 모든 시간은 33ms 단위 (1프레임 = 33ms).

- 틀: `docs/motion.template.md`. 컬러 · 폰트는 `design.md`, 배경 · 영상 글자색 · 영상 글자 크기는 `docs/video.md`에서만.
- 이동 거리 · 크기 변화량 · 위치는 이 문서에서 정하지 않는다. 장면마다 정한다 (Pattern 파일에 정해 둔 값은 그대로 쓴다).

## 1. Primitives

### Duration (6단계)
| 토큰 | 값 | 프레임 |
|---|---|---|
| `dur-xs` | 133ms | 4f |
| `dur-s` | 200ms | 6f |
| `dur-m` | 433ms | 13f |
| `dur-l` | 600ms | 18f |
| `dur-xl` | 933ms | 28f |
| `dur-2xl` | 1933ms | 58f |

### Easing (4종)
| 토큰 | 값 | 상태 |
|---|---|---|
| `entrance` | `cubic-bezier(0.15, 0.85, 0.55, 0.95)` | 측정값 |
| `exit` | `cubic-bezier(0.45, 0.05, 0.85, 0.15)` | **파생값 (측정 아님)** — `entrance`를 시간 방향으로 뒤집음 |
| `standard` | `cubic-bezier(0.55, 0, 0.1, 0.95)` | **추정값** |
| `flick` | `cubic-bezier(0.2, 0.425, 0, 0.997)` | 측정표 근사. 카드 레일에 씀 |

네 곡선 모두 y값이 0–1 안에 있다. 목표값을 넘어갔다 돌아오지 않는다.

### Blur (과하지 않게, 시간 · 곡선은 해당 Semantic)
| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `blur-in` | 4px → 0 | 텍스트 등장 (`enter` 안에서) |
| `blur-out` | 0 → 4px | 헤드라인 퇴장 (`exit` 안에서) |
| `blur-focus` | 초점 밖 4px · 초점 자리 0 | 폰 이어지는 이동(4-6)에서 카메라가 보는 곳만 또렷하게. 초점이 옮겨 갈 때는 카메라 이동과 같은 곡선 (soural 참고, 값은 `blur-in`과 같은 크기로 정함) |
| 전환 | 없음 | 빛 줄기 · 점 수렴 · 줌 통과로 움직이는 묶음에는 흐림을 주지 않는다 |

## 2. Semantic

| 토큰 | Duration | Easing | 쓰는 곳 |
|---|---|---|---|
| `enter` | `dur-m` | `entrance` | 요소가 들어올 때 · 줄이 다시 자리 잡을 때 |
| `exit` | `dur-s` | `exit` | 요소가 나갈 때 |
| `emphasis` | `dur-l` | `entrance` | 이미 있는 요소 강조 (숫자 세기 · 배지 · 버튼 반응 · 진행 바) |
| `transition` | `dur-m` | `standard` | 화면 전환 · 카메라 이동 (4-7) |
| `stagger` | `dur-s` (간격) | 없음 | 여러 요소가 차례로 나올 때 다음 요소까지의 간격 |

- 되돌아오는 강조(눌림 1 → 0.96 → 1, 배지 1 → 1.04 → 1)는 `emphasis` 곡선 하나(18f)로 하고, 둘로 나누지 않는다.
- 진행 바가 차오를 때 진행 글자(`mission-card-progress-text`)도 같은 `emphasis`로 함께 오른다.

## 3. Patterns

한 줄 요약만 둔다. **자세한 값 · 순서 · 변수는 `src/patterns/<파일>` 맨 위 주석**에 있다. 주석에 "구현 없음"이라고 적힌 파일은 가져다 쓰지 않고 그 주석대로 장면에서 만든다. "머무름"은 4-2.

| Pattern | 하는 일 | 쓰는 토큰 | 파일 |
|---|---|---|---|
| 오프닝 글자 | 첫 프레임부터 첫 단어가 보이고 나머지 단어가 올라온 뒤 머묾 | `enter` · `stagger` · `blur-in` | `headline.html` (`firstVisible`) |
| 텍스트 등장 | 단어마다 마스크 상승(기본) · 즉시 붙이기(`mode:"instant"`) · 단어별 나타나기, 강조 단어 하나는 `video-accent` | `enter` · `stagger` · `emphasis` · `blur-in` · `blur-out` | `headline.html` |
| 단어 겹쳐 바꾸기 | 같은 자리에서 한 단어가 다음 단어로 바뀜 | `exit` · `enter` · `dur-s` 겹침 | `word-swap.html` |
| 그어 지우기 | 글자 위에 선을 긋고 지운 뒤 다음 글자 | `enter` · `exit` · `video-strike` | `strike.html` |
| 강조 단어 색 바꾸기 | 단어들이 차례로 muted → accent → text | `emphasis` · `stagger` | `word-highlight.html` |
| 타이핑 | 문자열을 같은 간격으로 쳐 넣음 | `enter` | `typing.html` |
| 따라 읽기 | 화면보다 긴 히어로 문장을 카메라가 따라가며 단어 색이 차례로 바뀜 (오프닝 · 엔드만) | `dur-2xl` · `standard` · `emphasis` · `stagger` | `follow-read.html` |
| 단어 벌어짐 | 히어로 문장이 나갈 때 단어들이 바깥으로 벌어지며 퇴장, 끝 프레임이 컷 | `exit` | `word-spread.html` |
| 카드 순서 등장 | A 카드 1→2→3 같은 방향 / B 카드 레일 튕김 | `enter` · `stagger` · `flick` · `dur-2xl` · `dur-xl` | `card-stack.html` |
| 물량 장면 | screens · parts를 작게 벽처럼 깔고 한 방향으로 흐름 | `enter` · `transition` | `wall.html` |
| 버튼 눌림 | 커서 없이 버튼 눌림 한 번, 버튼 쪽으로 밀고 들어감 | `emphasis` | `button-press.html` |
| 눌림 링 | 버튼이 눌리는 순간 눌린 자리에서 링이 퍼지며 사라짐 | `emphasis` · `video-logo-ring` | `press-ring.html` |
| 카드 눕혀 등장 | 제품 카드가 뒤로 누운 상태(rotateX만)에서 세워지며 들어옴 (기울기 값 미정) | `enter` | `card-tilt.html` |
| 배지 강조 | 배지 enter 뒤 크기 1 → 1.04 → 1 한 번 | `enter` · `emphasis` | `badge-pulse.html` |
| 숫자 카운트업 | 0 → 최종값, 폭 고정 | `emphasis` | `count-up.html` |
| 숫자 공개 | 최종값 enter 뒤 단어가 한 프레임에 붙음 (합계 32f) | `enter` · `stagger` | `number-reveal.html` |
| 폰 화면 전환 | 기본 컷, 필요할 때 폰 전체를 한 그룹으로 옮김 | `transition` | `phone-switch.html` |
| 폰 밀고 들어가기 | 숫자 한 자리 바뀐 뒤 dolly + 뒤로 눕기 | `stagger` · `dur-l` | `phone-push.html` |
| 폰 솟아오르기 | 폰이 기울어진 채 솟아오르고 parts가 내려오거나 목록 안에 쌓임 | `dur-2xl` · `entrance` · `enter` · `stagger` | `phone-rise.html` |
| 상시 드리프트 | 모든 장면 카메라 1 → 1.04 일정 속도 | 없음 (`none`) | `drift.html` |
| 빛 줄기 전환 | `video-streak`이 화면을 쓸고 지나가며 장면이 바뀜 | `transition` · `exit` · `enter` | `light-streak.html` |
| 점 수렴 | 앞 장면 묶음이 한 점으로 줄고 그 점에서 다음 요소 | `transition` · `enter` | `converge.html` |
| 엔드 카드 | 슬로건 상승 → 로고 아이콘 → 아이콘 뒤에서 로고 글자 | `enter` · `stagger` · `blur-in` | `end-card.html` |
| 로고 빛 맞음 | 아이콘 뒤 링이 퍼지고 빛이 한 번 번짐 | `emphasis` | `logo-hit.html` |
| 엔드 바탕 바꾸기 | 로고가 다 나온 뒤 바탕이 `video-end-gradient`로 아래부터 차오름 | `transition` | `end-shift.html` |
| 영상 공통 배경 | 바탕 · 점 격자 · 빛 · 노이즈, 빛 흐름 | 없음 (`none`) | `bg.html` |

## 4. 장면 규칙

레퍼런스의 구성 문법(장면 종류 · 크기 비율 · 배경 · 카메라)을 16:9에 맞춘 규칙. 좌표는 가져오지 않는다.

### 4-1. 장면 종류
| 종류 | 화면에 있는 것 | 개수 |
|---|---|---|
| 글자 장면 | 문장 하나 또는 숫자 하나. UI 없음 | **오프닝 · 엔드 카드만** |
| 제품 장면 | 헤드라인(왼쪽) + `src/parts/` 또는 카드 묶음(오른쪽) | 제한 없음 |
| 폰 화면 장면 | 헤드라인(왼쪽) + `src/screens/*.png` 한 장을 폰 프레임 안에(오른쪽) | **기본 최대 2개. 레퍼런스에 폰 화면 구성이 있으면 최대 4개** (아래) |
| 물량 장면 | `screens` · `parts`를 작게 여러 장 (폰 화면 장면으로 세지 않음). 위에 `video-headline`을 얹을 수 있음 | 제한 없음 |

- 16:9를 살려 헤드라인과 화면 · 부품을 한 장면에 나란히 둔다.
- 폰 화면 장면 개수: 그 영상의 `_plan/references.md` "가져올 것"에 폰 화면 구성(폰 이어지는 이동 · `phone-rise` · `phone-push` 등 폰 프레임 안 화면이 주인공인 항목)이 하나라도 있으면 최대 4개, 없으면 최대 2개.
- 같은 종류는 최대 2개까지 연속. 폰 화면 하나에서 Pattern을 여러 개 이어 쓰면 Pattern마다 한 장면으로 센다.
- 강조 장면(결과 · 완료)은 글자와 제품을 한 장면에 같이 둘 수 있다. 주인공은 하나 (docs/video.md 5장).

### 4-2. 길이 · 텍스트 최소 유지
| 항목 | 값 |
|---|---|
| 짧은 장면 (숫자 하나 같은 비트) | `dur-xl` ~ 32f (1067ms) |
| 일반 장면 | `dur-2xl` ~ 108f (3600ms) |
| 전체 | **15초(450f) 이하** (장면 + 전환 합) |
| 머무름: 짧은 정보 (숫자, 한두 단어, 강조 크기) | 움직임이 끝난 뒤 `dur-m` |
| 머무름: 문장 (본문 · 라벨 최소 이상) | 움직임이 끝난 뒤 `dur-xl` |
| 머무름: 작은 보조 글자 (보조 최소 ~ 본문 최소) | 장면 끝까지 (중간에 퇴장하지 않음) |

- 머무름은 그 글자의 움직임 기준이다. 글자가 머무는 동안 제품 · 카메라 등 다른 요소는 계속 움직여도 된다.
- 글자 크기 구분은 docs/video.md 1장. 배경으로 쓰는 앱 화면 속 글자 · parts 안 글자는 예외.

### 4-3. 동시에 움직이는 요소
- **최대 4개**: 주 요소 1개 + 따라 움직이는 요소 최대 3개.
- 한 그룹으로 같이 움직이는 것(폰 화면 전체, 줄 전체)은 1개로 센다. 배경 빛과 카메라 흐름은 세지 않는다.
- `stagger`로 차례로 나오는 요소도 겹치는 순간 4개를 넘지 않게 간격을 잡는다.

### 4-4. 크기
| 대상 | 규칙 |
|---|---|
| 헤드라인 | 보조 `video-headline` 72–88px · 히어로 `video-hero` 200px (docs/video.md 3장). 히어로는 영상마다 2회 이상 |
| 글자 장면의 숫자 | 숫자 줄 폭이 화면 폭의 40–60% |
| 제품 클로즈업 | 화면 폭 90–95% 또는 화면 높이 80% 중 먼저 닿는 크기. 더 크게는 일부만 확대 |
| 나란히 배치의 제품 | 헤드라인 옆에 둘 때는 화면 높이 65–75% (클로즈업 규칙 대신) |
| parts 원본 | 인터랙션이 있는 parts는 HTML(`src/parts/*.html`), 나머지는 4x PNG. 4x 전까지 PNG는 2x의 1.5배까지 |
| 카드 여러 장 | 폰 목업 안에서는 앱 화면 그대로 세로로. 목업 밖에서는 묶음 폭이 화면 폭의 90%, 가로로 (물량 장면은 `wall.html`) |
| 작은 parts (배지 등) | 주인공이면 가장 큰 요소, 보조면 헤드라인보다 작게 `video-shadow-ui`로 띄움 |
| 폰 프레임 | 높이 = 영상 높이의 88% (`video-phone-height`) |
| 폰 기울기 | 화면 속 글자가 보이는 동안(머무름 · 카메라 이동 중) 기울기 **최대 25°** (rotateX · 비스듬히 보는 시점 모두). 등장 중 잠깐 지나가는 각도는 Pattern 값 그대로 (예: `phone-rise.html` 시작 35°) (soural 참고) |

### 4-5. 배경
- 배경은 2종: **어두운 배경**(docs/video.md 2장 기본)과 **밝은 배경**(`video-bg-light`). 장면마다 바꿔 쓸 수 있고, 같은 배경이 3장면 넘게 이어지지 않게 한다.
- 어두운 배경 위 글자는 `video-text` · 강조 `video-accent`, 밝은 배경 위 글자는 `color-text` · 강조 `color-primary`.
- 엔드 카드는 `video-end-gradient` (어두운 바탕에서 시작해 엔드 바탕 바꾸기로 바뀌어도 된다). 그 밖에 화면 전체를 `color-bg` · `color-primary` 단색으로 칠하지 않는다.
- 장면이 바뀌면 빛이 `video-light-pos` 다음 번호에서 시작하고, 장면 안에서는 `video-light-drift`(초당 화면 폭 3%, easing 없이).

### 4-6. 카메라 (상시 드리프트 + 장면 카메라 하나)
- **상시 드리프트** (기본): 모든 장면. 아래 카메라는 드리프트 위에 하나만 더한다. 글자 장면 · 강조 장면은 드리프트만.
- **밀고 들어가기**: 제품 클로즈업 · 버튼이 주인공인 폰 장면. 장면 내내 배율 1 → 1.16, `standard`.
- **줌 통과**: 제품 장면 → 숫자 장면처럼 이어질 때 1번만. 다음 장면 요소 속으로 `transition`.
- **따라가기** (옵션): 화면보다 긴 문장을 진행 방향으로 따라간다.
- **폰 이어지는 이동** (옵션, soural 참고): 바닥에 놓인 폰을 비스듬히 보는 시점에서 화면 한 곳 클로즈업 → 화면을 따라 위로 → 넓은 샷 → 화면 꺼짐. **폰 화면 장면 2개로 센다** (4-1 개수에 넣음. 레퍼런스에 이 구성이 있으면 최대 4개라 다른 폰 화면 장면을 2개 더 넣을 수 있다): 장면 A = 클로즈업 → 위로, 장면 B = 넓은 샷 → 화면 꺼짐. A와 B 사이는 컷 없이 카메라가 이어지고 (`phone-switch.html` 한 그룹 이동), 각 장면 안 카메라는 `transition`, 초점은 `blur-focus`. 기울기는 4-4 폰 기울기, 넓은 샷의 폰은 화면 높이 60% 이상. 폰 안에는 `src/screens/*.png`만.

### 4-7. 장면 전환
- 기본은 컷. 움직임이 이어지는 전환은 빛 줄기 · 점 수렴 · 줌 통과 · 폰 화면 전환.
- 앞 장면 `exit`가 끝난 프레임이 컷이고, 다음 장면 `enter`는 그 프레임부터 시작한다. 앞뒤 장면 글자가 같은 프레임에 함께 보이지 않는다.

## 5. 금지 목록

- **오버슈트 · 바운스**: 목표값을 넘었다 돌아오는 움직임. y값이 0–1 밖인 cubic-bezier, 감쇠비 1 미만 스프링 = 목표를 넘었다 돌아오는 스프링 (예: damping 12 · stiffness 120, 12.8% 넘침), `back` · `elastic` · `bounce`.
- **회전 등장**: 요소가 화면 평면 안에서 돌면서(rotateZ) 들어오는 움직임. 원근 기울기(rotateX)가 바뀌며 들어오는 것은 회전 등장이 아니다.
- **글리치**: 화면이나 글자가 깨지거나 어긋나는 효과.
- **레퍼런스의 색 · 폰트**와 **16:9 좌표를 그대로 쓰는 것**. 구성 문법(4장)은 가져와도 된다.
