# soural — 폰 목업 구도 변화 (참고용만)

출처: @0xSoural https://x.com/0xSoural/status/2112533459604328479 · 원문은 같은 폴더 `prompt.md`
결과물 · starter · 공통 조각에 넣지 않음. 프롬프트 문장은 옮기지 않고, 구도 변화 기법만 참고한다.

## 가져올 것 — 폰 목업 구도 변화만

| 순서 | 구도 | 설명 |
|---|---|---|
| 0 | 바닥에 놓인 폰을 비스듬히 보는 시점 | 폰은 바닥에 눕혀 두고, 카메라가 위에서 비스듬히 내려다본다. 바닥 색은 가져오지 않고 우리 배경(`docs/video.md` 2장) 위에 둔다 |
| 1 | 화면 한 곳 클로즈업 | 화면의 한 부분(숫자 · 버튼 등)에 바짝 다가간다 |
| 2 | 화면을 따라 위로 | 같은 이동이 끊기지 않고 화면을 따라 위쪽으로 올라간다 |
| 3 | 넓은 샷 | 뒤로 빠져 폰 전체가 보인다 |
| 4 | 화면 꺼짐 | 넓은 샷에서 화면이 꺼지며 끝난다 |

- **카메라는 한 번 이어지는 이동**: 1 → 2 → 3이 컷 없이 하나의 경로로 이어진다. 도중에 멈추거나 방향이 튀지 않는다.
- **30mm 느낌**: 광각처럼 휘지 않고, 망원처럼 납작하지도 않은 자연스러운 원근.
- **보는 곳에 초점**: 카메라가 보는 곳만 또렷하고 나머지는 살짝 흐리다.

## 가져오지 않을 것

| 무엇 | 원문 항목 | 이유 |
|---|---|---|
| 캐릭터 (복셀 마스코트 · 점프 · 분열) | HERO | 우리 화면에 없는 요소 |
| 앱 아이콘 · 상표 (타사 앱 아이콘 · 피드 카드 · 배지) | APPS | 타사 상표, 우리 화면에 없는 UI |
| three.js · 4K / 120fps 렌더 · 프레임 합성 설정 | FORMAT | 우리 렌더는 HyperFrames · 1920×1080 · 30fps (`docs/motion.md`) |
| 사운드 · 비트 맞추기 · 음량 | SOUND | 이번 범위 밖 |
| 레퍼런스의 색 · 재질 · 시간표(초) · BPM | SET · BEATS | `docs/motion.md` 5장: 레퍼런스의 색 · 좌표를 쓰지 않음. 시간은 우리 토큰으로 |

## 우리 조건

- 폰 안에는 `src/screens/*.png`만 넣는다. 화면 속 문구는 그 PNG에 실제로 있는 것만.
- 글자가 읽히게 폰 기울기는 **최대 25°**.
- 넓은 장면(3 · 4)에서 폰은 **화면 높이의 60% 이상**.
- 그 밖의 값(시간 · 곡선 · 크기 · 배경 · 베젤)은 `docs/motion.md` · `docs/video.md`에서만.
