# 영상 룩 (16:9 · 1920×1080, 앱 UI에는 쓰지 않음)

톤은 숏폼 썸네일이 아니라 런칭 필름: 단정한 보조 글자와 화면을 채우는 히어로 글자의 대비, 넓고 부드러운 빛, 주인공 하나. 컬러 원본은 design.md, 움직임 · 시간은 docs/motion.md.

## 1. 텍스트 최소 크기

| 항목 | 값 |
|---|---|
| 보조 (작은 글자) 최소 | **36px** |
| 본문 · 라벨 최소 | **42px** |
| 강조 (숫자 · 헤드라인 · 슬로건) | **72px 이상** (히어로는 3장 `video-hero`) |
| 피그마 → 영상 배율 | **피그마 크기 ×2.8** |

**적용 범위**
- 영상에 새로 얹는 글자(헤드라인 · 숫자 · 슬로건 등)에만 적용한다.
- 배경으로 쓰는 앱 화면(`src/screens/*.png`) 속 글자는 예외다.
- `src/parts/` 부품 안의 글자도 제품 화면 글자로 보고 예외로 둔다 (부품은 피그마 값 그대로).
- 피그마 스타일 ×2.8이 위 최소값보다 작으면 최소값을 쓴다.

**이유**
1. **화면 배율.** 피그마의 사이즈는 모바일 화면 기준(가로 약 375–390pt)이다. 1080px 영상은 폰에서 이 폭으로 줄어 보이므로 약 1/2.8로 축소된다. 36px → 폰에서 약 13pt, 42px → 약 15pt(`Text/body` 크기)로 보인다.
2. **피그마 스타일을 그대로 쓰면 너무 작다.** `Text/caption` 12px·`Text/eyebrow` 11px를 영상에 1:1로 넣으면 폰에서 약 4pt가 되어 읽을 수 없다. 그래서 스타일 크기에 ×2.8을 곱한다.
3. **보는 시간.** 영상 글자는 멈춰서 읽을 수 없고 정해진 시간만 보인다. 그래서 앱 화면보다 한 단계 크게 잡는다.
4. **얇은 굵기 주의.** 400(Regular)은 압축된 영상에서 뭉개지기 쉽다. 36–42px 크기의 글자는 600(SemiBold) 이상을 쓴다.

## 2. 영상 공통 배경

**배경은 2종(어두운 · 밝은), 엔드 카드는 그라데이션** (motion.md 4-5). 아래 표가 기본인 어두운 배경. 아래에서 위로 네 겹: 바탕 → 점 격자 → 빛 → 노이즈.

| 토큰 | 값 |
|---|---|
| `video-bg` | `#18191b` |
| `video-dots` | 점 색 `#ffffff`, 지름 2px, 간격 24px 격자, 불투명도 **6%** (겨우 보일 정도, 허용 3–6%. 4%는 렌더 후 영상에서 보이지 않았음) |
| `video-light` | `#3759de`, 빛 중심 불투명도 22% → 가장자리 0%, 타원 화면 폭 70% × 화면 높이 140% (넓고 부드러운 세로 빛 띠) |
| `video-light-pos` | 장면 시작 때 빛 중심 (x, y), 화면 왼쪽에 치우침: ① 0% 40% · ② 6% 55% · ③ 2% 30% · ④ 8% 50% · ⑤ 4% 65% · ⑥ 0% 45% · ⑦ 이후 ①부터 반복 |
| `video-light-drift` | 장면이 이어지는 동안 빛이 오른쪽으로 이동. 속도는 motion.md |
| `video-noise` | 흑백 노이즈, 불투명도 4%, 움직이지 않음 |
| `video-streak` | 빛 줄기 전환(`src/patterns/light-streak.html`): `video-light` #3759de, 가운데 불투명도 40% → 가장자리 0%, 폭 화면 폭 25%, 기울기 30° |

- **빛은 한쪽(왼쪽 가장자리)에 치우쳐서 시작하고, 점 격자 위를 아주 천천히 지나간다.** 가운데 원형 스포트라이트는 쓰지 않는다.
- 빛은 점 격자 위에 `screen`으로 겹친다. 빛이 지나가는 자리의 점이 조금 더 밝게 보인다.
- 장면이 바뀌면 빛은 `video-light-pos` 다음 번호에서 다시 시작한다 (컷과 함께).
- 노이즈는 빛 그라데이션의 띠(밴딩)를 감추는 용도. 눈에 띄면 안 된다.

**밝은 배경 · 엔드 그라데이션** (네 겹 구성 · 빛 위치 · 흐름은 어두운 배경과 같음)

| 토큰 | 값 |
|---|---|
| `video-bg-light` | `color-surface` #f7f7f8 |
| `video-dots-light` | 점 색 `color-text` #18191b, 지름 2px, 간격 24px, 불투명도 4% |
| `video-light-light` | `color-primary` #3759de, 빛 중심 불투명도 8% → 0%, 타원은 `video-light`와 같음 |
| 밝은 배경 글자 | 글자 `color-text` #18191b · 보조 `color-text-muted` · 강조 `color-primary` #3759de (#f7f7f8 대비 약 5 : 1) |
| `video-end-gradient` | 엔드 카드 바탕: 아래 `color-primary` #3759de → 위 `video-bg` #18191b, 글자 · 로고는 `video-text` |
| `video-dim` | 바쁜 배경(물량 장면 벽 등) 위 글자를 읽히게 덮는 층: `video-bg` #18191b 불투명도 60%. 그 위 글자는 `video-text` (launch-b 승인) |

## 3. 글자

| 토큰 | 값 |
|---|---|
| `video-text` | `#ffffff` |
| `video-text-muted` | `#ffffff` 불투명도 64% |
| `video-accent` | `#91a4ed` (`video-bg` 대비 7.3 : 1) |
| `video-headline` | Pretendard **SemiBold(600)**, 크기 = 화면 높이의 **6–8%** (1080 기준 64–88px), 행간 비율은 `Text/display`(34/28) |
| `video-hero` | 히어로 헤드라인: Pretendard 600, **200px** (화면 높이 약 18.5%), 행간 비율 `Text/display`(34/28). 가장자리 잘림은 한 글자까지 허용. 영상마다 2회 이상 |
| `video-tracking-tight` | `-0.02em` (헤드라인 자간) |
| `video-strike` | 그어 지우기 선: `video-accent` #91a4ed (밝은 배경에서는 `color-primary`), 두께 = 글자 크기의 6%, 가로줄 하나 |
| `video-logo-height` | 로고(`src/parts/logo.html`) 전체 높이 = 같은 영상의 `video-headline` 글자 크기 (72–88px). 색은 `video-text` |

- **굵기**: 헤드라인은 SemiBold(600)까지. Bold(700) 이상은 쓰지 않는다. 한글은 같은 굵기에서 영어보다 무거워 보여서 한 단계 낮춘다.
- **크기와 1장의 관계**: 보조 헤드라인(`video-headline`)은 1장 강조 최소(72px)도 지켜야 하므로 실제로 쓰는 범위는 **72–88px**. 히어로는 `video-hero`.
- **색**: 글자는 단색(`video-text`). 글자에 그라데이션 금지.
- **강조**: 한 문장에서 한 단어만 `video-accent`로. 굵기 · 크기 차이로 강조하지 않는다.
- **문구**: 짧은 선언형, 느낌표 없이. 문장형 강조(예: "미션 완료.")는 마침표로 끝내고, 짧은 헤드라인 · 라벨 · 슬로건은 마침표 없이 쓴다.
- `color-primary`(#3759de)를 그대로 글자에 쓰면 `video-bg` 대비 3.05 : 1이라 읽기 어렵다. 그래서 밝은 톤(`video-accent`)을 쓴다.

## 4. 폰 프레임 (모바일 화면을 넣는 부품)

| 토큰 | 값 |
|---|---|
| `video-phone-bezel` | `#2f3032` |
| `video-phone-bezel-width` | 화면 폭의 3% |
| `video-phone-radius` | 화면 폭의 12% (안쪽 화면 모서리는 바깥보다 베젤 두께만큼 작게) |
| `video-phone-height` | 프레임 높이 = 영상 높이의 88% |
| `video-shadow-device` | 폰 솟아오르기 그림자: `0 60px 120px` 검정 40% 한 겹 (launch-b 승인) |

- `src/screens/*.png`는 폰 프레임 안에 넣어서 보여주는 것이 기본이다 (motion.md 4-1).

## 5. UI 요소 (parts)

| 토큰 | 값 |
|---|---|
| `video-shadow-ui` | `0 16px 48px` 검정 45% + `0 2px 6px` 검정 30% (두 겹) |
| `video-shadow-ui-soft` | `0 8px 24px` 검정 12% + `0 1px 3px` 검정 8% (두 겹). 밝은 배경 위 카드 묶음 · 캐러셀처럼 카드가 여러 장 겹쳐 보일 때 은은하게 (launch-b 수정 요청 4) |
| `video-logo-ring` | 로고 빛 맞음(`logo-hit.html`) · 눌림 링(`press-ring.html`) 링: `video-accent` #91a4ed, 선 2px, 지름 아이콘 높이 → 3배, 불투명도 60% → 0% |
| `video-logo-glow` | 로고 빛 맞음 빛 번짐: `video-light` #3759de 22%, 크기 아이콘 높이 3배, 한 번 번졌다 사라짐 |

- **주인공은 한 장면에 하나.** 글자가 주인공인 장면에서는 parts가 보조, parts가 주인공인 장면에서는 글자가 보조.
- 보조로 쓰는 parts는 그대로 붙이지 않고 `video-shadow-ui`로 바닥에서 띄운다. 크기는 주인공 글자보다 작게 (안의 글자 높이가 헤드라인보다 작게, 1장 보조 최소 36px 이상).
